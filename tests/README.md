# آزمون خودکار

```bash
npm i jsdom        # یک‌بار
node tests/run-tests.js
```

- فایل‌های `IPC-7352/*.html` را در jsdom با `runScripts: dangerously` باز می‌کند (شبیه باز کردن آفلاین در مرورگر).
- ۲۵۶ بررسی دارد: ایرادهای `Problem.md`، اندازه‌گذاری روی نقشه، سازگاری اعداد با هندسهٔ پدها، داینامیک بودن پنل، جابه‌جایی/بزرگ‌نمایی (تا ۲۰×) و جا شدن برچسب‌ها در کادرشان.
- جای اجرای واقعی Altium، Chromium یا آزمون لایه‌های PCB را نمی‌گیرد.

### آزمون مرورگر واقعی (اختیاری)
`tests/browser-preview.cjs` با `playwright-core` و `@sparticuz/chromium`، سرور فعال پورت 8080 را تست می‌کند: چهار نمونه، ابعاد SVG، بازیابی ذخیرهٔ خراب، خطای ورودی و دکمهٔ بازیابی. اجرا: `node tests/browser-preview.cjs`. بستهٔ Chromium به کتابخانه‌های سیستمی NSS/NSPR نیاز دارد. در sandbox فعلی با `LD_LIBRARY_PATH=/tmp/chromlibs/lib` اجرا شد. تصاویر آزمایشی فقط در `/tmp/ipc-*.png` ذخیره می‌شوند.

گروه ۱۶ مرجع مستقل برای سوراخ و پد پایه‌های گرد/مربع/مستطیل، دو فرایند لحیم، NPTH، override، تبدیل واحد، خروجی Altium و حلقهٔ مسی مثبت دارد.

گروه ۱۷ شیار گرددو‌سر با ابعاد نهایی کاربر، فرمول هندسی حلقهٔ یکنواخت، دو مثال نام‌گذاری 5.2.3، جاگرفتن اسمی گوشه‌های پایه، CSV صریح، منع خروجی Altium گردِ اشتباه و تبدیل واحد در حد دقت ورودی را بررسی می‌کند.

آخرین اجرای این تغییر: **226 موفق، 0 ناموفق**. گروه‌های 18/19 مدل بدنهٔ THT، بیشینهٔ ابعاد نمونه‌های سازنده، نام‌گذاری، SOT-23-5/6 و انتخاب شکل مستقل از ویرایش دستی را پوشش می‌دهند. آزمون مرورگر، نمایش و ماندگاری شکل پد و تعداد پد مدل‌های پنج/شش‌پایه را هم بررسی می‌کند. عبور آزمون‌ها گواه انطباق کامل استاندارد یا تأیید ساخت نیست.

آخرین اجرای رفع ریشه‌ای: **256 موفق، 0 ناموفق**. گروه‌های 20/21 تمام 18 مدل قابل تنظیم، نگهداری ورودی هر پکیج، THT→SMD و بازیابی حالت ذخیره‌شده با مدل THT باقی‌مانده را پوشش می‌دهند. آزمون مرورگر همین مسیر خرابی را نیز بررسی می‌کند.
